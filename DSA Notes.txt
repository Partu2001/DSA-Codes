***************************************************************  4.CIRCULAR LINKED LIST  ********************************************************
* Diff Singly and Circular Linked List :
1.Singly Linked List : It contains Data and Next(Node).
2.Circular Linked List : It conrains previous (Node),Data,Next(Node).

** CIRCULAR LINKED LIST :
-Advantages : 
  Every node is accessible from given node.
  Singly linked list - only in one direction till last node.But in circular linked list we can continue after last node.
-Limitations :
  Infinite loop while traversing if head node not identified.

* APPLICATION OF CIRCULAR LINKED LIST :
1.Music Play List (Next song loops back)
2.Multi Player Games  

* CREATING CIRCULAR LINKED LIST :
-Create a new node using createNode method.
-Case 1 : Check if the list is empty
  Assign new nodes reference to last.
  Set the next of new node to null.
  Return the control.
-Case 2 : Adding at the end of the list.
  Take temp reference.Move the reference till the last node in the list.
  Make new node next refer to first node.
  Set the curr refer to the new node.
  Lastly set the new node as the last node. 

-In Circular Linked List last holds the address of first node.	
-Unlike singly Linked List nodes can be traversed from start to end again and again.
-Circular Linked List are two types :
  1.Singly Circular Linked List
  2.Doubly Circular Linked List

****************************************************************  10.TREE  ***************************************************************

* DEFINATION :
-It is a non linear data structure having finite set of nodes.
-It is collection of vertices and edges.
-An edge is a pair of vertices which are connected.
-The vertices should be connected such that we should be able to travel one node to another.
-There should not be anu closed path.

* TERMINLOGIES OF TREE :
-The number of sub trees of a node is called as its degree.
-It is equal to number of outgoing edges from the node.
-Nodes having degree 0 are called leaf nodes / terminal nodes of a tree.
-Nodes having degree greater than 0 are called internal nodes / non terminal nodes.
-Degree of tree is maximum degree of the nodes in the tree.

* BINARY TREE :
-A binary tree is an empty tree or it is a finite set of nodes with a root and two disjoint binary trees called the left sub tree and right sub tree.
-The degree of any node in a binary tree is at most 2.

* TRAVERSAL OF TREE :
1.Inorder Traversal :
 Left Child-Root-Right Child

2.Preorder Traversal : 
 Root-Left Child-Right Child

3.PostOrder Traversal :
 Left Child-Right Child-Root

**************************************************************  12.THREADED BINARY TREE  **********************************************

* NEED FOR THREADED BINARY TREE :
-A Binary Tree of n nodes has n -1 edges.
-In every node you have two pointer hence you have 2n pointer storing the address to the children.
  Out of these only n + 1 pointers are used.
-The remaining n + 1 pointers are having null.

* Key Concepts of ThreadsPurpose :
-In a binary tree with \(n\) nodes, there are \(n + 1\) NULL pointers. 
-Threading replaces these NULL pointers with Threads to link nodes directly to their neighbors in a specific traversal order (usually inorder).

* Mechanism : 
-The left child pointer (if NULL) is used to store the inorder predecessor.
-The right child pointer (if NULL) is used to store the inorder successor.

* Advantage: 
-These threads allow for tree traversal without the use of a stack or recursion,
-saving memory and potentially increasing speed.


*****************************************************************  13.GRAPH  ***********************************************************

* GRAPH :
-A data structure that consists of a set of nodes (also called vertices) and set of edges that establish relationship (connections) between the nodes.
-A Graph G consists of two sets V and E.
 V is a finite non empty set of vertices.
 E is a set of pairs of vertices or nodes called edges.

* TYPES OF GRAPHS :
1.Udirected Graph
2.Directed Graph
3.Strongly Connected Graph
4.Weakly Connected Graph
5.Network / Weighted Graph
6.Complete Graph

1.UNDIRECTED GRAPH :
-An Undirected Graph is a graph in which the edges have no direction. 
-If there is an edge between two vertices A and B, 
-you can travel from A to B and from B to A.
-Notation: A — B
-Ex : 
      A
     / \
    B---C
     \
      D

2.DIRECTED GRAPH :
-It is a graph in which each edge is represented by specific direction or by directed pair < v1,v2>.
 Here v1 is tail and v2 is head of the edge.
 Directed graph are shortly called as digraphs.

3.STRONGLY CONNECTED GRAPH : 
-A directed graph is strongly connected if every vertex is reachable from every other vertex.
-That means:
 There is a path from A to B.
 There is also a path from B to A
-Ex : 
        A
     ↗ ↘
    C ← B

4.WEAKLY CONNECTED GRAPH :
-A directed graph is weakly connected if it becomes connected after ignoring the direction of its edges.
-Example
A → B → C
There is :
A → B ✔
B → C ✔
C → A ✘
So it is not strongly connected.

5.NETWORK OR WEIGHTED GRAPH :
-A Network Graph is a graph in which vertices (nodes) are connected by edges (links) to represent relationships or the flow of information, goods, or resources between them.
-Network graphs are widely used in computer networks, transportation systems, social networks, communication systems, and electrical circuits.
-Ex :
         A
      / | \
     B  C  D
      \ | /
        E

6.COMPLETE GRAPH :
-A Complete Graph is a graph in which every vertex is directly connected to every other vertex by exactly one edge.
-It is denoted by Kₙ, where n is the number of vertices.
-Ex : 
       A
     /|\
    / | \
   B--|--C
    \ | /
     \|/
      D
